## 5. Critical operator-facing flows

### 5.1 `neoth chat` (CLI hot path)

`cli/chat.rs::run_chat_with` orchestrates:

1. Load freedom.yaml + assemble operator context (`memory/operator_md::assemble`)
2. Resolve prompt from arg or stdin
3. Spawn WAL writer
4. Write RAW_TEXT (0x10) frame — capture `raw_event_id` for profile pipeline
5. Write PROVIDER_REQUEST (0x21) frame (hashed metadata)
6. Skill router (keyword match against installed skills)
7. MCP catalogue injection (renders enabled servers' tool catalogue into system prompt)
8. Persona prefix (tweaks.toml)
9. Slash command dispatch (handles `/cmd args`)
10. PrePipeline + PreProviderCall hooks (TOML hooks engine)
11. **Three-way branch** (council trigger evaluates first):
    - Council Convene → `run_council_debate` → on Split, `dispatch_council_with_recovery` (callosum + CH-11 profile injection)
    - MCP autoroute enabled → `run_mcp_dispatch_loop` (iterative tool-call parser)
    - Default → `provider.complete(req)`
12. PostProviderCall hooks (last chance to mutate reply)
13. PROVIDER_RESPONSE (0x22) frame
14. **Mirror-refusal detection + cause classification + R-04 recovery**:
    - If refusal detected → emit 0x16 REFUSAL_OBSERVED with `{class, cause, cause_confidence, ...}`
    - If `config.refusal_recovery.enabled` → call `try_recover_multi` (R-01); on `Recovered`, replace `response_text` downstream; on full exhaustion, 0x1A REFUSAL_PERSISTENT emitted
15. ADR auto-extraction (DECISION:/Beschluss:/ADR: markers → `~/.neoth/adr/NNNN-<slug>.md`)
16. SESSION_ARCHIVE append (operator-readable MD)
17. **Profile pipeline post-reply** (opt-in via `config.profile.learn_enabled`): replay_once + run_pipeline against `raw_event_id`; 15s timeout cap
18. Two-stage review gate (only when `--agent` dispatched + config flag on)
19. PreEgress hooks
20. Print to stdout

### 5.2 `neoth serve` (daemon channel path)

`cli/serve.rs::build_pipeline_handler` per inbound message:

1. Media extraction (audio→transcript, image→embedding cached)
2. PreChannelIngress hooks
3. Rate-limit (per-channel-per-sender token bucket)
4. Ingress sanitizer (strip control markers)
5. RAW_TEXT + CHANNEL_INGRESS (0x32) WAL frames — capture `ingress_event_id`
6. Permission gate (autonomy fail-closed in daemon)
7. Slash command dispatch
8. PreProviderCall hooks
9. **Three-way branch** (same as CLI):
    - Council Convene → `dispatch_council_with_recovery` (channels gain callosum)
    - MCP autoroute → `run_mcp_dispatch_loop`
    - Default → `provider.complete`
10. Mirror-refusal + cause + recovery (R-04 wire)
11. ADR extraction
12. CHANNEL_EGRESS (0x33) WAL frame
13. SESSION_ARCHIVE
14. **Channel profile pipeline post-reply** (opt-in, `block_in_place` Send-escape for !Send rusqlite)
15. PreEgress hooks
16. Reply text returned to channel adapter

### 5.3 Refusal recovery flow

```
Refusal text from provider.complete
  └─→ refusal_detect::classify  (surface class)
  └─→ refusal_cause::classify_cause  (cause)
  └─→ 0x16 REFUSAL_OBSERVED audit emitted
  └─→ try_recover_multi (R-01):
        for reframing in applicable_reframings(cause, catalogue, disabled):
          if attempt_count >= max_attempts: break
          0x19 REFUSAL_REROUTED audit emitted (per attempt)
          let reframed = reframing.apply(original_prompt, original_system)
          let retry = provider.complete(reframed)
          if !refusal_detect::classify(retry).is_refusal():
            return Recovered { completion: retry, reframing_id }
        all exhausted → 0x1A REFUSAL_PERSISTENT audit emitted
  └─→ If Recovered: response_text = recovered.text (downstream sees fix)
      Else: original refusal stays
```

Operator surface: `neoth refusal {classify, cause, reframings, disable, enable, patterns}`. Configuration: `freedom.yaml::refusal_recovery.{enabled, disabled_reframings, max_attempts}` + env overrides `NEOTH_REFUSAL_RECOVERY_DISABLE=1`.
