## 6. Critical operator-facing flows

### 6.1 `neothd` startup (after Session 15)

1. Operator launches `neoth-gui` (default operator path).
2. `MainWindow` renders `WizardStep::ModeSelection` als first screen.
3. Operator picks GUI card → continue zu Welcome → 7 more wizard steps → Done writes freedom.yaml + credentials.yaml.
4. ODER operator picks CLI card → `on_cli_mode_chosen` callback prints `neoth init` + `std::process::exit(0)`.
5. Operator runs `neoth init` in shell → CLI wizard mirror.

### 6.2 `neoth chat <msg>` mit slash command

1. `run_chat()` loads freedom.yaml + V03-08 consent gate.
2. `run_chat_with()` reads stdin prompt.
3. `parse_invocation(prompt)` → if `Invocation::Command { name, args }`:
4. `slash::load_all()` merges built-ins + `~/.neoth/commands/*.toml`.
5. **NEW Pick #31**: if `cmd.action.is_some()` → `dispatch_action()` → operator sees outcome → return Ok (skip LLM).
6. Else: render prompt template + LLM round-trip.

### 6.3 `/reload` voll wired (Pick #31)

1. Operator types `/reload` in chat.
2. `dispatch_action(ReloadConfig, ...)` writes sentinel-file at `~/.neoth/.reload-requested`.
3. Daemon polling loop in `cli/serve.rs:290` picks up within 2s.
4. `ReloadController::try_reload()` validates immutable fields + atomic `ArcSwap`.
5. WAL frame `0xD0 CONFIG_RELOADED` emitted.
