### 5.3 Council recursion flow (E-2 Phase 2 Session 13)

```
run_council_debate(config, req)
  ├─ Arc<FreedomConfig>::new(config.clone())
  ├─ build_hemisphere_with_config(arc, Left, req)  → ProviderHemisphere{config: Some(arc)}
  ├─ build_hemisphere_with_config(arc, Right, req) → ProviderHemisphere{config: Some(arc)}
  ├─ build_hemisphere_with_config(arc, Cere, req)  → ProviderHemisphere{config: Some(arc)}
  └─ depth = config.inference.hemisphere_council_depth.get()  (default 1)
  └─ run_debate_with_depth(prompt, hash, depth, left, right, cere)
       ├─ run_one(role, h, prompt, depth) × 3 in FuturesUnordered
       └─ each calls h.ask_with_depth(prompt, depth)
            ├─ depth ≤ 1 OR config is None → flat (provider.complete)
            └─ depth > 1 + config arc present:
                 ├─ build 3 sub-hemispheres via build_hemisphere_with_config(arc, role, ...)
                 ├─ run_debate_with_depth(prompt, hash, depth - 1, sub_l, sub_r, sub_c)
                 └─ aggregate: winning_text OR first usable_response
```

**Cost**: 3^depth leaf LLM calls per outer-hemisphere invocation. depth=2 = 9 leaf. depth=4 (cap) = 81 leaf. Default depth=1 (flat) — recursion only fires on explicit opt-in.

### 5.4 Refusal recovery flow

```
Refusal text from provider.complete
  └─→ refusal_detect::classify  (surface class)
  └─→ refusal_cause::classify_cause  (cause)
  └─→ 0x16 REFUSAL_OBSERVED audit emitted
  └─→ try_recover_multi (R-01):
        for reframing in applicable_reframings(cause, catalogue, disabled):
          if attempt_count >= max_attempts: break
          0x19 REFUSAL_REROUTED audit emitted (per attempt)
          let reframed = reframing.apply(original_prompt, original_system)
          let retry = provider.complete(reframed)
          if !refusal_detect::classify(retry).is_refusal():
            return Recovered { completion: retry, reframing_id }
        all exhausted → 0x1A REFUSAL_PERSISTENT audit emitted
  └─→ If Recovered: response_text = recovered.text
      Else: original refusal stays
```
