## 3. Three silent production defects found while fixing tests

1. **Windows audit-RPC served one connection per daemon lifetime** (`72e93437`).
   `accept()` took the pending pipe instance before awaiting `connect()`, and
   `run_accept_loop` awaits it inside a `select!` — one cancellation destroyed the
   only listener. Fail-closed on accept errors then killed the loop. Invisible
   because `AuditSink::DaemonRpc` is best-effort. Unix unaffected → Linux CI never saw it.
2. **Pipe DACL compared against `GENERIC_ALL`** (`4c023a25`), which Windows never
   returns after generic mapping. Every bind failed, silently.
3. **Tone classifier cancelled itself out** (`d3f061b2`) — `"correct"` matches inside
   `"incorrect"`, so the most explicit correction phrase scored neutral.

All three were invisible under a permanently red suite. That is the cost of red main.
