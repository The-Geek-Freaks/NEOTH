# Free For Dev: AI & Hosting Services

[INTENT: Übersicht und Nutzung kostenloser Cloud- & AI-Dienste für Entwickler]

## Major Cloud Providers (Free Tiers)
[INTENT: Limits und Free-Tiers der großen Cloud-Anbieter für AI-Infrastruktur aufzeigen]
- **Google Cloud Platform (GCP):** Kostenloses Cloud Run, Cloud Functions. **Google Gemini API**: Kostenloser Zugang zu Gemini 1.5 Pro/Flash (15 Req/Min, 1.500 Req/Tag). Kaggle/Colab für Jupyter Notebooks & GPU/TPU.
- **Amazon Web Services (AWS):** EC2 t2.micro/t3.micro (750h/Monat für 12 Monate), Lambda (1 Mio. Requests/Monat), DynamoDB (25GB).
- **Microsoft Azure:** Azure Functions (1 Mio. Requests/Monat), Cognitive Services (AI/ML APIs wie Computer Vision mit Free-Tier).
- **Cloudflare:** Workers (100k Req/Tag), Pages, R2 (10GB/Monat). 

## AI, ML & Data APIs
[INTENT: Spezialisierte APIs für Data, AI und Machine Learning auflisten]
- **AlphaAI:** Financial News API & MCP Server (20 Req/Min).
- **Brave Search API:** AI/LLM Context API für RAG Pipelines ($5 monatliche Credits).
- **Composio:** Integration Platform für AI Agents & LLMs (200+ Tools).
- **Firecrawl:** Website Crawler/Scraper, wandelt Seiten in LLM-ready Markdown um (1.000 Credits/Monat).
- **Hugging Face:** Build, Train, Deploy NLP Models. Kostenlos bis 30k Input-Zeichen/Monat.
- **Maxim AI:** Simulieren, Evaluieren und Überwachen von AI Agents (Free Forever für 3 Seats).
- **Tavily AI:** API für Online-Suche, Research und AI Agents.
