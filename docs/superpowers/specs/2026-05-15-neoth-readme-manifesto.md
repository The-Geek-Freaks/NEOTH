# NEOTH README Visual & Structural Manifesto

This document defines the mandatory rules for the NEOTH GitHub README to ensure it remains "Insanely Great" and consistent with the Sovereign Buddy identity.

## 1. Visual Hierarchy (The "Cinematic" Rule)

Every README section must feel like a frame from a high-end industrial film.

- **The Hero Banner:** A mandatory 1280x400 ultra-wide banner at the very top. It must feature the Master Logo (v1.1) centered on a #0d0d0d background with the "Neural Pulse" animation style.
- **The "Vanta" Spacing:** Use excessive vertical whitespace between major sections to evoke the Zen/Steve Jobs aesthetic. If it feels like too much space, add 10% more.
- **Visual Dividers:** Do not use standard Markdown `---`. Use custom HTML gradients that fade from `#00ff80` (Green) to transparent.

## 2. Structural Pillars (The "Trinity" Layout)

The README must be organized into exactly three primary "Acts" reflecting the brand narrative:

### Act I: The Sovereignty (Authority)
- **Content:** The high-level vision. NEOTH as the Emperor of Terra.
- **Style:** Large typography, bold statements. Minimalist text.
- **Mandatory Quote:** A single centered quote about knowledge or power (Thoth/Warhammer style).

### Act II: The Buddy (Relationship)
- **Content:** How it helps the user. "Your Buddy, Your Life".
- **Style:** Use the "Buddy Icons" (Crystalline Cube, Binary Bolt). 
- **Interactive Feel:** Showcase the Slint GUI screenshots in high-res with 40px rounded corners and drop shadows.

### Act III: The Engine (Technical)
- **Content:** The Rust architecture, WAL, Tiered Memory, and Qwen3.
- **Style:** Brutalist code blocks. Use `#1a1a1a` backgrounds for terminal outputs.
- **Badges:** All badges must be "Flat Square" style, using only the brand colors (Green, Pink, Blue).

## 3. Mandatory Style Rules

| Element | Rule |
| :--- | :--- |
| **Typography** | Use `<h1>` for Act titles only. All other headers must be `###`. |
| **Coloring** | Knowledge-focused text should be highlighted with `00ff80` (where supported). |
| **Tone** | Senior Software Engineer meets Ancient Egyptian Priest. Direct, authoritative, but helpful. |
| **Screenshots** | Every screenshot must be framed in a "Device Mockup" (MacBook or Studio Display style). |
| **GIFs/Videos** | The "Neural Pulse" must be present as a subtle background looping GIF in the header. |

## 4. The "No-Cringe" Clause

- **No Emojis:** Use them only in the "Buddy" section, and only sparingly.
- **No Marketing Fluff:** No "revolutionary", "game-changing", or "disruptive". Use "Sovereign", "Obligated", "Neural".
- **No Standard Templates:** Never use a boilerplate "Awesome README" template. NEOTH is its own category.
