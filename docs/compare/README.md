# NEOTH Compare

These pages explain how NEOTH positions itself against adjacent personal AI
assistants without making sloppy claims.

## The one-glance version

Things NEOTH ships that none of the compared projects document — each with
the command that proves it on your machine:

| Only in NEOTH | Prove it |
| :-- | :-- |
| Collapse prediction on its own runtime ([Babel-Index](../babel-index.md)): pre-registered failure labels, self-calibrating, Brier-scored | `neoth babel status` |
| HMAC-chained append-only audit log you can verify yourself | `neoth verify` |
| Evidence-linked profile memory behind explicit consent | `neoth profile pending` |
| WASM plugin capability sandbox that refuses and audits over-level calls at runtime | `neoth plugin ledger` |
| Fail-closed trust boundaries: cloud calls, profile extraction, channel egress all denied until granted | `neoth privacy audit --last 30d` |

The point is not that competitors are bad — they optimize for different jobs.
The point is that every claim above is a mechanism you can inspect, not a
slogan.
