### W50 immutable-commit review context

`neoth review --impact-context --commit SHA` accepts one commit selection,
rejects branch-range selectors and merge commits, resolves an immutable
base/target pair, and carries the canonical physical repository root through
impact analysis and the OCR argv. Structural context uses a bounded private
background file. Prepared and terminal receipts retain hashes and provenance,
not raw diff, source/test text, user background, OCR configuration, or OCR
output.

Ordinary `review` keeps its established OCR availability/run behavior. The
impact-only probe suppresses automatic update only in its own child process.
The bounded real-Git/SQLite OCR-context receipts and direct-child-only
cancellation proof passed. They do not prove a live authenticated OCR call,
automatic update, write-capable code-map open, or Windows `cmd /C`
descendant-tree cleanup.

### W52 Code Sessions read surface

The read-only Code Sessions consumer accepts an explicit root and one source:
working tree, staged changes, or a committed base/target pair. It displays
typed affected-test evidence and errors, caps visible rows at 32, and discloses
omissions. Empty observed evidence remains uncertainty rather than a no-test
claim.

Each analysis is bound to canonical root, physical root identity, and lifecycle
operation. Root or source changes invalidate visible output. During an active
operation, Native Coding and lifecycle controls remain interlocked until the
precise terminal handoff; stale completions cannot release a newer analysis.
The W52 headless-controller integration targets belong to the final
seven-contract gate and have no selected-libtest claim. No GUI link, render,
accessibility, screenshot, runtime, or exact-head remote claim follows.

### W53 built-in outline enrichment boundary

`FreedomConfig.code_map.outline_enrichment` is default-off. An accepted
immutable configuration snapshot can prepare one bounded **untrusted** sidecar
only for the built-in `codegraph_outline` route. Disabled or ineligible calls
retain ordinary outline behavior. This does not extend enrichment to generic
native Read, Grep, Glob, Bash, or other tools.

Eligibility binds the configured server to the trusted built-in executable's
canonical identity, a valid launcher, read-only posture, exact codegraph-server
arguments/database selection, and the exact allowed built-in tool set. The
configured `PreToolUse` decision precedes lookup; a Block stops planning and
lookup. After the ordinary outline response, the plan rechecks
cancellation/deadline, root, generations, and freshness before adding one
bounded sidecar. That sidecar remains untrusted and cannot rewrite the original
call.

The real-gate fixture constructs a SQLite snapshot, crosses the authenticated
gate and stdio-server route, reconstructs the exact `codegraph_outline`
request binding for `{"path":"outline.rs"}`, and requires one allowed
`McpToolInvocation` WAL decision with that SHA-256 plus one successful
`MCP_TOOL_CALLED` frame.
